# 投行工作台 · 移植到新电脑说明

本压缩包是**完整可运行版**：源码 + 数据库 + 离线依赖包（`_wheels`）都已打包，
拷到任意 Windows 电脑解压后，**无需联网**也能一键装好依赖并启动。

## 三步启动

1. 解压本包到任意目录（路径别含空格更稳，如 `D:\投行工作台`）
2. 双击 `投行工作台\一键安装并启动.bat`
3. 脚本会自动：检测 Python → 建虚拟环境 → 用 `_wheels` 离线装依赖 → 打开浏览器

浏览器访问：**http://127.0.0.1:5000**
初始账号：`admin`　初始密码：`th2026`（首次登录会强制修改密码）

## 前置条件（仅一项）

- 电脑需装 **Python 3.9+**（推荐 3.13）。装的时候勾选 **"Add Python to PATH"**。
  下载：https://www.python.org/downloads/
- 若没外网也没关系：`_wheels` 里已备好 cp313 / cp314 两套离线 wheel，可离线安装。

## 数据与回退

- 全部业务数据在 `投行工作台\workbench.db`，已随包带走。
- 版本历史见 `版本记录.md`，可用 `git checkout <版本号> -- .` 回退。
- 每次迭代改完，运行 `python 版本快照.py -m "说明" --zip` 即可再存版本。
