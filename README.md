# 投行部数智化工作台

投行部日常业务管理工具，Python Flask + SQLite 单体应用，单文件后端、零前端构建。

> 本仓库为**公开代码版**：不含任何业务数据库与客户数据（`workbench.db` 等已在 `.gitignore` 中排除）。
> 本地运行时首次启动会自动建库并创建默认管理员。

## 功能

| 模块 | 说明 |
|---|---|
| 首页看板 | 业务概览、待办、快捷入口 |
| 商机管理 | 粘贴导入（规则解析）、Excel 批量导入/导出、四类商机台账 |
| 科技金融 | S70 贷款导入（50 列表头自适应）、总览看板（年初余额/数据日期/分类余额）、明细（多条件查询/分页/导出/编辑/批量删除/敏感字段脱敏/详情） |
| 综合融资 | 固贷商机台账（按规则从商机文本解析 9 个字段，查询/分页/导出/编辑） |
| 债券融资 / 资本市场 | 项目推进台账、阶段漏斗 |
| 跨表匹配 | 两张表按关键列精确 + 模糊匹配，导出对照结果 |
| 素材库 / 初稿生成 | 素材归档与初稿模板生成 |
| 用户与权限 | 用户管理（含邮箱）、RBAC 角色菜单、邮箱验证码注册（游客角色） |

## 快速开始

```bash
python -m venv .venv
.venv/Scripts/pip install -r 投行工作台/requirements.txt
cd 投行工作台
../.venv/Scripts/python app.py
```

打开 http://127.0.0.1:5000 ，默认管理员 `admin / th2026`（首次登录强制改密）。

可选环境变量：

| 变量 | 作用 |
|---|---|
| `WB_DB_PATH` | 指定数据库文件（自动化测试用副本，避免影响生产数据） |
| `WB_PORT` | 指定监听端口（默认 5000） |

## 数据安全

- `workbench.db` 含真实业务数据，**不入库**；`版本备份/`、`.venv/`、`_wheels/` 同样排除
- 自动化测试请使用 `WB_DB_PATH=副本.db WB_PORT=5001` 起独立实例，不要直接操作生产库
